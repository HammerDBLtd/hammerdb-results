SUBMISSION GUIDE

Four clear steps

  1. Choose the original artifact. No pipeline or additional config file is required to upload it.
  2. Identify the submitter. Add your GitHub account, optional company logo and description.
  3. Declare workload intent. For TPROC-C, record UAW and durability settings or leave it unclassified.
  4. Submit. Save the file in GitHub and finish the pre-filled pull request.

Important: Submission target: Loading repository…. On TPC-Council Pages, contributors propose changes by PR to TPC-Council. This form does not write files directly.
